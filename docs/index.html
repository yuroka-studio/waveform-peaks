waveform-peaks

Turn songs into compact waveform data for web players: N normalised bars, peak and RMS.

Nothing is uploaded. Your files are decoded and analysed inside this tab with the Web Audio API. This page makes no network requests and has no analytics.

    Same algorithm as the waveform-peaks command line tool (MIT, Yuroka Studio). Browsers decode at their own audio rate, so sampleRate here may differ from the file's; the bars are practically the same.

    Prefer a terminal? The repository has a command line tool that reads WAV directly and needs no browser.
